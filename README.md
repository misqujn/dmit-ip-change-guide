## DMIT 换 IP 是什么意思？为什么要换？

简单说：DMIT 换 IP，指的是把 VPS 当前绑定的 IPv4 地址替换成另一个新地址，原来那个地址系统回收，不可恢复。

国内用 VPS 最怕的一件事就是 IP 被 GFW 屏蔽。一旦被墙，国内所有机器都无法访问这个 IP，但机器本身运行正常，境外可正常连接。常见场景：搭建科学上网工具、跑爬虫、使用 API 调用服务——这些都属于 IP 被墙的高风险用途。

DMIT 的换 IP 政策规定：如果你的 IP 确认被墙（即 ICMP 在国内完全不通），可以申请更换新的 IPv4，分配机制是系统随机抽取，属于原生 IP，纯净度有保障。

## DMIT 换 IP 政策详解：免费、付费、自助三种模式

这是很多人搞不清楚的地方，因为 DMIT 的规则按产品线和计费周期都有区分。

### 免费换 IP 的条件

**Premium 和 Eyeball 系列（包括洛杉矶、香港、东京）**：

只要 IP 被墙（确认 ICMP 全国不通），且账户套餐的剩余服务时间超过 30 天，每 15 天可以申请一次免费更换。月付方案可以使用免费换 IP，但要求同样是套餐剩余天数大于 30 天才行。

加购 **IP Care+** 附加服务的用户：换 IP 间隔缩短到每 7 天一次，另外如果急需立刻换，支付 $5 可以立即处理，不用等冷却期。

其他情况（不符合免费条件）：$5 一次，每次换完需等 7 天才能再次申请。

有一点要注意——DMIT 不保证新换的 IP 在全球所有地区都能访问，包括中国大陆。Premium 和 Eyeball 系列有承诺首次连接可到达，但如果你加购了 IP Guarantee+（不是 IP Care+，是另一个附加服务），就有额外的保障，新 IP 会确认在敏感地区可用后才下发。

### 新订单保护期

买了 7 天内的新机器，申请换 IP 会收费。别刚下单当天就提申请，等满一周再说。

### Tier 1 系列

T1 是国际线路，没有面向国内的优化，IP 被墙的概率低很多。T1 系列换 IP 的规则和其他系列一样，但实际上用 T1 的人通常不太会碰到被墙问题。

## 自助换 IP 怎么操作？

讲真，这是 DMIT 近几年体验提升最明显的一个地方。以前换 IP 必须提工单等客服，手动处理，快的话半小时，慢的话得等到第二天。现在部分套餐已经可以自助完成，完全不用等人。

**洛杉矶 LAX Pro / EB 系列（AN4 和 AN5 平台）：**

1. 登录 DMIT 控制面板（clientarea）
2. 进入「服务」或「实例管理」，找到对应的 VPS
3. 找到「更换 IP」选项，点击提交
4. 提交完成后，**手动重启实例**，新 IP 才会生效
5. 新 IP 由系统随机分配，重启后几分钟内就能用上

如果新分配的 IP 出现异常（比如刚换又不通），直接提工单，官方客服通常很快就处理。

**香港 HKG / 东京 TYO 的 Pro 和 EB 系列：**

也支持自助发起换 IP 申请，但需要人工审核。提交请求后，审核时间一般在 24 小时内。审核通过后，你有 48 小时的确认窗口，点击确认后 10 分钟左右 IP 就下发完成。

## 换 IP 后要做什么？

换完 IP 之后，除了重启实例，还有几件事要确认：

1. 更新所有依赖这个 IP 的配置：代理软件的服务端配置、域名解析记录（如果有绑定域名）、防火墙白名单里的旧 IP 条目
2. 测试新 IP 国内连通性，工具可以用 ping 或者直接 curl 测试
3. 原 IP 不可恢复，换之前想清楚

## FAQ

**Q：月付套餐可以免费换 IP 吗？**

可以。只要套餐剩余服务时间大于 30 天，月付套餐同样可以每 15 天申请一次免费换 IP（IP 被墙才能申请）。但月付套餐本身到期时间短，建议选季付或年付，这样剩余天数更容易维持在 30 天以上。

**Q：DMIT 换 IP 能指定要哪个 IP 吗？**

不能。新 IP 由系统随机分配，无法指定。如果新 IP 分配后有问题（如路由异常、无法访问），提工单说明，客服会协助处理。

**Q：DMIT 换 IP 之后原来的 IP 能找回来吗？**

找不回来。旧 IP 换完就被系统回收了，没有任何途径恢复，请在换之前确认好。

**Q：如果 IP 只是部分端口被封，算"被墙"可以免费换吗？**

按 DMIT 的规则，如果 ICMP（ping）还通、只是部分端口不通，这种情况算有条件可达，会被判定为非完全被墙，免费换 IP 的申请可能不会通过，会被要求付费处理。

**Q：加 IP Care+ 服务值得吗？**

看用途。如果你的 IP 被墙频率高（比如每个月都会遇到），IP Care+ 把免费换 IP 间隔从 15 天缩短到 7 天，还支持支付 $5 随时立刻换，算下来还是划算的。如果你的 IP 很少被封，不用加这个附加服务。
